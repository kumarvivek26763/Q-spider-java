# Q Spider Java Practice Folder

This folder contains Java practice files and notes from the Q Spider Java course. It includes:

- **Day 4**: Exercises and examples from Day 4 of the course (First.java, calculator.java)

- **CLASS_OBJECT**: Examples demonstrating classes and objects (Animal.java, Acceses.java, User.java, Product.java)

Feel free to explore and learn!
